How these four bands map to the eight pipeline statuses

Sourcing = Sourced + Applied Screened = Screening + Shortlisted Interview = Interview Offered = Offer + Hired

Rejected has no band — it is an exit from every stage, not a stage of its own. Counting it anywhere would make the bands stop summing to the total. This mapping is a decision, not a default; it belongs in the module doc before it is built.
