This is the only duplicate the candidate is told about

Applying twice to the same posting is something they did and can verify, so telling them is helpful and reveals nothing. Everything else stays silent: if their phone number matches a candidate from a different job two years ago, the application is quietly attached to that record and the page says nothing. Saying “welcome back” would confirm to anyone typing phone numbers into this form which ones are in the database.

Blank fields fill in; filled fields never get overwritten

If the older record has no email and this form supplies one, it is added. If it has a different email, the older one stands and this one is not silently replaced — a recruiter resolves that, because an anonymous form is not allowed to edit an existing person's contact details.

Zawgyi is fixed here, not later

A name typed on a Zawgyi keyboard is normalised to Unicode as it arrives. If it were stored raw, this candidate would be invisible to every Burmese search from that day on — and nobody would ever notice, because a search that finds nothing looks like a search with no matches.

Email is optional, phone is not

The reverse of the usual web form, and correct for this market: a field-role applicant may have no email address in daily use but certainly has a phone with Viber. Making email required would filter out exactly the candidates this posting is looking for.

Three custom fields, because the recruiter chose three

The block under the divider is rendered from this posting's schema. Twenty are allowed; every one is a reason to abandon the form on a phone. The builder shows “3 of 20 used” rather than an empty allowance inviting someone to fill it.
