## 1. Codebase Exploration & Candidate 360 Context

### 1.1 Architecture & Dependency Mapping
The frontend is a Vite + React SPA (`frontend/internal`) supported by shared npm packages:

  - `aiApi.matchCandidate(req: MatchCandidateRequest): Promise<CandidateMatchAnalysis>`

### 1.2 Existing Candidate 360 SlideOver Structure (`CandidateSlideOver.tsx`)
`CandidateSlideOver.tsx` renders a full-height drawer using `Sheet` (`size="xl"`). Currently, it contains 5 tabs:
1. **Overview**: Candidate metadata, Cover Note, Application Form Custom Answers.
2. **CV Viewer (`CvAndDocumentsTab`)**: Single CV file upload, raw text display with Zawgyi normalization badge, parsed profile human review form.
3. **Stage History**: Timeline of pipeline status changes.
4. **Scorecards**: Interview rounds and interviewer panel scorecard status.
5. **Notes & Debrief**: Application notes and `@mention` feedback.

## 2. Smart Match Badge & Breakdown UI Component Design

### 2.1 Component Structure & UI Placement
Smart Match evaluates candidate compatibility against a target job posting using Claude AI.

1. **Header Match Badge (`SmartMatchHeaderBadge`)**:
   - Placed in `CandidateSlideOver` header next to `candidateName` and `StatusPill`.
   - Displays percentage match (e.g. `87% Match`) with color-coding based on overall score & recommendation:
     - **`StrongMatch` (80%–100%)**: Emerald/Success badge (`variant="success"`), e.g. `87% Match`.
     - **`GoodMatch` (60%–79%)**: Primary/Blue badge (`variant="primary"`), e.g. `72% Match`.
     - **`PossibleMatch` (40%–59%)**: Amber/Warning badge (`variant="warning"`), e.g. `52% Match`.
     - **`LowMatch` (< 40%)**: Red/Danger badge (`variant="danger"`), e.g. `34% Match`.
   - Clicking the badge opens the **Smart Match Breakdown Drawer / Panel**.

2. **Smart Match Breakdown Panel (`SmartMatchBreakdownPanel`)**:
   - Can be toggled inside an **"AI Insights"** tab or rendered as a slide-out drawer inside `CandidateSlideOver`.
   - Components of Breakdown Panel:
     - **Match Summary Header**: Overall score gauge/progress bar, recommendation pill, and executive summary text.
     - **Strengths & Gaps**: Two-column list highlighting top candidate strengths (green checkmarks) and key skill/experience gaps (amber alert icons).
     - **Criteria Compatibility Table**: List of evaluated criteria (e.g. *Years of Experience*, *Tech Stack Alignment*, *Domain Knowledge*, *Language Proficiency*) with individual scores (0-100) and AI rationale.
     - **Suggested Interview Questions**: List of tailored interview questions generated by Claude to probe identified candidate gaps.

### 2.2 Component Interface & State Specification

export interface SmartMatchBreakdownProps {

  jobPostingId: string;

```tsx
// Proposed UI Structure for Smart Match Section
export function SmartMatchSection({ candidateId, jobPostingId }: { candidateId: string; jobPostingId: string }) {
  const [analysis, setAnalysis] = useState<CandidateMatchAnalysis | null>(null);
  const [loading, setLoading] = useState(false);
  const [error, setError] = useState<ApiError | null>(null);

  const fetchMatch = async () => {
    setLoading(true);
    setError(null);
    try {
      const data = await aiApi.matchCandidate({ candidateId, jobPostingId });
      setAnalysis(data);
    } catch (err) {
      if (err instanceof ApiError) setError(err);
      else setError(new ApiError(500, 'Failed to fetch candidate match analysis.'));
    } finally {
      setLoading(false);
    }
  };

  // Render score badge, criteria breakdown, and suggested interview questions
}
```

## 3. Executive Summary Panel UI Design

### 3.1 Component Features & Layout (`ExecutiveSummaryPanel.tsx`)
Gemini AI generates executive candidate summaries with optional Burmese localization.

1. **Control Toolbar**:
   - **"Generate AI Summary" Button**: Primary action button. Disabled during fetch or when API key is missing.
   - **Language Switcher (Toggle Group)**:
     - `EN` (English - default)
     - `MY` (Burmese - Unicode)
     - `Bilingual` (Side-by-side / Dual English & Burmese summary)
   - **Audience Selector**:
     - `Internal`: Full recruiter details, compensation context, gap notes.
     - `Client`: Client-safe candidate dossier summary.
2. **Display Body**:
   - **Headline Banner**: Brief high-level summary line.
   - **Narrative Summary Paragraph**: Multi-line structured summary.
   - **Key Strengths Bullet Points**: Highlighted candidate qualifications.
   - **Suggested Interview Questions**: Tailored questions for hiring manager interview rounds.
   - **Bilingual Badge Indicator**: Shows `isBilingual: true` badge when Burmese content is rendered (`variant="cyan"`).
3. **Quick Actions**:
   - **Copy Text**: Copies executive summary markdown text to system clipboard.
   - **Export Document**: Downloads summary as `.md` file (e.g. `Executive_Summary_Jane_Smith.md`).

## 4. API Integration, Loading States & 402 Graceful Gating

### 4.1 AI API Endpoint Calling
Calls are dispatched to `aiApi` in `frontend/internal/src/lib/api.ts`:
- **Match Candidate**: `POST /api/ai/claude/match-candidate`
  - Body: `{ candidateId, jobPostingId }`
- **Executive Summary**: `POST /api/ai/gemini/executive-summary`
  - Body: `{ candidateId, jobPostingId, audience, language }`

### 4.2 Skeleton Loading States
During API requests, render animated pulse skeletons using `@recruitops/ui`:
- For Smart Match: `SkeletonCard` showing progress circle skeleton and 4 criteria row skeletons (`SkeletonRow`).
- For Executive Summary: `SkeletonText` (lines={5}) representing summary text generation.

### 4.3 402 Payment Required (Unconfigured API Key) Handling
Per **ADR-0008**, AI features are optional and API-key gated. If an installation has no API key set up, backend returns HTTP `402 Payment Required`.

#### Graceful UI Handling Strategy:
1. **Catching 402 Status Code**:
   ```ts
   if (err instanceof ApiError && err.status === 402) {
     setIsApiKeyConfigured(false);
     setErrorMessage('AI Provider API Key Not Configured');
   }
   ```
2. **Feature-Disabled UI Banner**:
   Instead of crashing or leaving a broken spinner, render an informative disabled state box:
   ```tsx
   <div className="rounded-md border border-warning-300 bg-warning-50 p-4 text-warning-800">
     <div className="flex items-center gap-2 font-semibold text-sm">
       <svg className="h-5 w-5 text-warning-600" fill="none" viewBox="0 0 24 24" stroke="currentColor">
         <path strokeLinecap="round" strokeLinejoin="round" strokeWidth={2} d="M12 9v2m0 4h.01m-6.938 4h13.856c1.54 0 2.502-1.667 1.732-3L13.732 4c-.77-1.333-2.694-1.333-3.464 0L3.34 16c-.77 1.333.192 3 1.732 3z" />
       </svg>
       AI Smart Match & Executive Summary Disabled
     </div>
     <p className="mt-1 text-xs text-warning-700">
       An AI Provider API Key (Claude / Gemini) has not been configured for this installation.
       Phase 1 manual candidate profiling and scoring remain fully operational.
     </p>
   </div>
   ```
3. **Disabled Trigger Controls**:
   Disable "Generate AI Summary" and "Re-analyze Smart Match" buttons with a tooltip indicating "Requires AI API key configuration".

## 5. Vitest Testing Strategy for Candidate 360 AI UI

### 5.1 Test Suite Organization
Create `CandidateSlideOverAi.test.tsx` inside `frontend/internal/src/features/pipeline/__tests__/`.

### 5.2 Required Test Cases (6+ Core Specifications)

1. **Smart Match Badge & Breakdown Drawer Rendering**:

   - Verifies score badge `87% Match` renders with `variant="success"`.
   - Verifies clicking breakdown expands criteria table, strengths, gaps, and suggested interview questions.

2. **Executive Summary Generation with EN / MY / Bilingual Language Switcher**:
   - Verifies clicking "Generate AI Summary" calls `aiApi.generateExecutiveSummary`.
   - Verifies switching language toggle to `MY` passes `language: "my"` in request payload.
   - Verifies `isBilingual: true` renders "Burmese Enabled" badge.

3. **Loading Skeleton Display During Async Requests**:
   - Mocks a pending promise for `matchCandidate` and `generateExecutiveSummary`.
   - Asserts skeleton placeholders (`animate-pulse`) are visible while loading.

4. **Graceful Handling of HTTP 402 Payment Required (Disabled Key State)**:
   - Mocks `aiApi.matchCandidate` to reject with `new ApiError(402, "AI API Key missing")`.
   - Asserts feature-disabled warning box is rendered.
   - Asserts application does not crash and Phase 1 candidate data remains accessible.

5. **API Error Handling & Retry Mechanism**:
   - Mocks `aiApi.generateExecutiveSummary` to reject with HTTP 500.
   - Asserts error alert is displayed with a "Retry" button.
   - Clicking "Retry" re-triggers API call and displays result on success.

6. **Clipboard Copy & Markdown Export Actions**:
   - Verifies clicking "Copy Summary" calls `navigator.clipboard.writeText` with summary content.
   - Verifies export trigger constructs downloadable file.
